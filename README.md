# Seint Seint Thu — Profile

A responsive React + Vite profile and portfolio starter.

## Run locally

```sh
npm install
npm run dev
```

## Customize

- Update the introduction, location, email, social links, and project cards in `src/main.jsx`.
- Adjust the color palette and responsive layout in `src/styles.css`.
- Replace the portrait illustration in the hero with a photo or your own artwork when ready.
